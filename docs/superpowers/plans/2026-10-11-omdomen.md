# Omdömen, implementationsplan

> **För agenter:** OBLIGATORISK UNDERSKILL: använd superpowers:subagent-driven-development (rekommenderas) eller superpowers:executing-plans för att genomföra planen uppgift för uppgift. Stegen använder kryssrutor (`- [ ]`) för uppföljning.

**Mål:** Kunder med en personlig länk kan skriva ett omdöme. Sebastian granskar det i verkstadspanelen, och publicerade omdömen visas på brädsidan eller beställningssidan med Product-uppmärkning (betyg och omdömen) för Google.

**Arkitektur:** Pages-funktionen `functions/api/omdome.js` tar emot omdömet och lägger det i D1-databasen `myrdahls-klick` (bindning `KLICK`), som fungerar som inkorg. Panelen (`verktyg/admin.js`) skapar inbjudningar, och när ett omdöme publiceras flyttas det till `src/_data/omdomen.json`. Eleventy läser bara den filen. Den rena logiken ligger i `lib/omdomen.js` (visning och strukturerad data) och `verktyg/omdomen.js` (panelens fil och koder).

**Teknik:** Eleventy 3 (Nunjucks), Cloudflare Pages Functions (ESM), D1, Resend, `node:test`. Testerna kör D1-frågorna mot `node:sqlite`, som finns i Node 22.19 men skriver en ExperimentalWarning. Den varningen är väntad.

**Spec:** `docs/superpowers/specs/2026-10-10-omdomen-design.md`

## Globala krav

- All text på sajten är på svenska och följer skrivreglerna i CLAUDE.md: aldrig tankstreck (– eller —), inga återbrukspåståenden, och en varm och saklig ton.
- Färger: bakgrund #F4EDDD, bläck #2B2118, guldbrun #8a5a2c, rost #8a3d2c, kort #FBF6E9, dämpad #57503F. I CSS används variablerna `--papper --black --guld --rost --kort --dov`.
- Typsnitt: bara EB Garamond, och Caveat för handskrivna lappar (`.lapp`).
- Ingen ny extern tjänst och inget anrop till tredje part från besökarens webbläsare.
- Allt i den strukturerade datan ska också synas på sidan.
- Publicerade omdömen bor bara i `src/_data/omdomen.json`. D1 är en inkorg för väntande omdömen.
- Granskningen får aldrig sålla på betyg. Panelens text vid Avslå säger exakt: "Avslå bara skräp, uppgifter om andra personer eller påhopp. Ett ärligt lågt betyg ska publiceras."
- Fält och gränser: `kod` 12 tecken `[A-Za-z0-9_-]`, `betyg` heltal 1 till 5, `namn` 1 till 40 tecken, `ort` 0 till 40 tecken, `text` 10 till 1500 tecken, kropp högst 8 kB.
- Repot är CommonJS. Pages-funktioner och `lib/*.mjs` är ESM.
- Kör `npm test` före varje commit. Hela sviten ska vara grön.

## Granskningsfokus

Fem fall som specen förutsätter men inte säger rakt ut, och som drabbar en verklig människa om de går fel:

1. **Kundtext med `</script>` eller HTML.** Texten hamnar i JSON-LD i ett `<script>`-block, på sidan och i panelen. Väntat beteende: den visas som text överallt och bryter aldrig ut ur sitt sammanhang. Prövas i uppgift 3 (`jsonld`-filtret escapar `<`) och i uppgift 6, där panelen bara använder `textContent`. Panelen är särskilt utsatt, eftersom ett skript där kan skriva filer.
2. **Ett återanvänt id.** Om SQLite gav ett nytt omdöme samma id som ett redan publicerat skulle Publicera tro att det redan fanns i filen och tyst hoppa över det. Väntat beteende: id återanvänds aldrig, vilket `AUTOINCREMENT` garanterar. Prövas i uppgift 2.
3. **Samma kod skickas två gånger,** till exempel vid dubbelklick eller två flikar. Väntat beteende: ett omdöme sparas, och det andra försöket får "Länken är redan använd" (410). Prövas i uppgift 2.
4. **Radbrytningar och styrtecken i texten.** Väntat beteende: stycken behålls, `\r\n` blir `\n`, högst en tom rad i följd, och inga styrtecken sparas. Prövas i uppgift 2.
5. **Publicera, och D1 svarar inte vid borttagningen.** Väntat beteende: omdömet ligger i filen, panelen säger att det ska tryckas igen, och nästa försök tar bara bort raden utan att dubblera. Prövas i uppgift 5.

```sql
-- Omdömen, se functions/api/omdome.js och verktyg/admin.js.
-- Ligger i samma databas som klicken, så wrangler.toml behöver ingen ny bindning.
-- Körs en gång mot den skarpa databasen:
--   npx wrangler d1 execute myrdahls-klick --remote --file=db/omdome.sql
-- och mot den lokala, för npm run preview:
--   npx wrangler d1 execute myrdahls-klick --local --file=db/omdome.sql
--
-- Databasen är bara en inkorg. Ett publicerat omdöme flyttas till
-- src/_data/omdomen.json, och ett avslaget raderas.

CREATE TABLE IF NOT EXISTS inbjudan (
  kod    TEXT PRIMARY KEY,   -- 12 tecken base64url, slumpad i panelen
  mal    TEXT NOT NULL,      -- brädans slug, eller 'bestallning'
  skapad TEXT NOT NULL,      -- 2026-10-10
  anvand TEXT                -- dagen omdömet kom in, null tills dess
);

-- AUTOINCREMENT med flit: utan det kan SQLite ge ett nytt omdöme samma id
-- som ett raderat, och id:t är det som skiljer omdömena åt i omdomen.json.
CREATE TABLE IF NOT EXISTS omdome (
  id     INTEGER PRIMARY KEY AUTOINCREMENT,
  kod    TEXT NOT NULL UNIQUE REFERENCES inbjudan(kod),
  mal    TEXT NOT NULL,      -- kopierat från inbjudan
  betyg  INTEGER NOT NULL,   -- 1 till 5
  namn   TEXT NOT NULL,
  ort    TEXT NOT NULL,      -- tomt om kunden inte vill
  text   TEXT NOT NULL,
  dag    TEXT NOT NULL       -- dagen det skrevs
);
```

```js
'use strict';

/*
 * En D1-attrapp ovanpå node:sqlite, så att funktionernas SQL körs på riktigt
 * i testerna. Bara det funktionerna använder: prepare, bind, first, all, run
 * och batch, som är en transaktion precis som i D1.
 */

const fs = require('node:fs');
const { DatabaseSync } = require('node:sqlite');

function fejkD1(...sqlFiler) {
  const db = new DatabaseSync(':memory:');
  for (const fil of sqlFiler) db.exec(fs.readFileSync(fil, 'utf8'));

  const kor = (sql, varden) => {
    const r = db.prepare(sql).run(...varden);
    return { meta: { changes: Number(r.changes) } };
  };
  const sats = (sql, varden = []) => ({
    bind: (...nya) => sats(sql, nya),
    first: async () => db.prepare(sql).get(...varden) ?? null,
    all: async () => ({ results: db.prepare(sql).all(...varden) }),
    run: async () => kor(sql, varden),
    _kor: () => kor(sql, varden)
  });

  return {
    db,
    prepare: (sql) => sats(sql),
    async batch(lista) {
      db.exec('BEGIN');
      try {
        const ut = lista.map((s) => s._kor());
        db.exec('COMMIT');
        return ut;
      } catch (e) {
        db.exec('ROLLBACK');
        throw e;
      }
    }
  };
}

module.exports = { fejkD1 };
```

```js
 * Tar emot omdömen från skrivsidan /omdome/.
 *
 * Bara den som har en kod från en inbjudan kan skriva. Sebastian skapar
 * inbjudan i verkstadspanelen och klistrar in länken i mejlet efter
 * leveransen. Varje kod ger ett omdöme.
 *
 * Omdömet läggs i D1-databasen (bindning KLICK, samma som klicken) och
 * väntar där tills Sebastian har läst det i panelen. Först då hamnar det i
 * src/_data/omdomen.json och på sajten, se db/omdome.sql.
 *
 * Ingen IP-adress och ingen webbläsaruppgift sparas, bara det kunden själv
 * skrev och dagen.
 *

 * beställningarna. Saknas nyckeln sparas omdömet ändå, men ingen notis går.

  from '../../lib/sidsvar.mjs';

const MAX_KROPP = 8 * 1024;
const KOD = /^[A-Za-z0-9_-]{12}$/;

// En rad: namn och ort. Styrtecken och radbrytningar blir mellanslag.
function rad(v) {
  return String(v == null ? '' : v).replace(/[\u0000-\u001f\u007f]/g, ' ').replace(/\s+/g, ' ').trim();
}

// Brödtext: stycken behålls, men aldrig mer än en tom rad i följd.
function stycke(v) {
  return String(v == null ? '' : v)
    .replace(/\r\n?/g, '\n')
    .replace(/[\u0000-\u0009\u000b-\u001f\u007f]/g, '')
    .replace(/[ ]+\n/g, '\n')
    .replace(/\n{3,}/g, '\n\n')
    .trim();
}

// Formulärets fält som ett omdöme, eller { fel } med en mening till kunden
function rensa(falt) {
  const kod = rad(falt.kod);
  if (!KOD.test(kod)) return { fel: 'Koden från mejlet saknas eller är felskriven. Använd länken i mejlet, så fylls den i av sig själv.' };
  if (!/^[1-5]$/.test(rad(falt.betyg))) return { fel: 'Välj ett betyg, från en till fem stjärnor.' };
  const namn = rad(falt.namn);
  if (!namn) return { fel: 'Skriv vad du vill stå som, till exempel ditt förnamn.' };
  if (namn.length > 40) return { fel: 'Namnet får vara högst 40 tecken.' };
  const ort = rad(falt.ort);
  if (ort.length > 40) return { fel: 'Orten får vara högst 40 tecken.' };
  const text = stycke(falt.text);
  if (text.length < 10) return { fel: 'Skriv minst några ord om brädan.' };
  if (text.length > 1500) return { fel: 'Texten får vara högst 1 500 tecken.' };
  return { kod, betyg: Number(rad(falt.betyg)), namn, ort, text };
}

// Bara från sajtens egen skrivsida. En främmande sida kan inte sätta Origin
// till vår domän.
function franSajten(request) {
  const origin = request.headers.get('origin');
  if (!origin) return false;
  try {
    return new URL(origin).host === new URL(request.url).host;
  } catch (e) {
    return false;
  }
}

function notis(omdome, mal, avsandare, mottagare) {
  const vad = mal === 'bestallning' ? 'en bräda efter mått' : 'brädan ' + mal;
  return {
    from: avsandare,
    to: [mottagare],
    subject: 'Nytt omdöme väntar, ' + omdome.betyg + ' av 5',
    text: 'Ett omdöme har kommit in för ' + vad + ', från ' + omdome.namn + '.\n\n' +
      'Läs det i verkstadspanelen (npm run admin, sedan Omdömen) och publicera eller avslå.\n'
  };
}

export async function onRequestPost({ request, env, waitUntil }) {
  const mottagare = env.MOTTAGARE || STANDARD_MOTTAGARE;
  const avsandare = env.AVSANDARE || STANDARD_AVSANDARE;
  const fel = (rubrik, text, status) => svarssida(rubrik, text, mottagare, status);

  if (!franSajten(request)) {
    return fel('Något gick fel', 'Omdömet måste skickas från sidan på myrdahlstra.se.', 403);
  }
  if (!env.KLICK) {
    return fel('Omdömen tas inte emot just nu', 'Omdömet kunde inte sparas. Mejla det gärna i stället, då lägger jag in det.', 503);
  }
  if (parseInt(request.headers.get('content-length') || '0', 10) > MAX_KROPP) {
    return fel('För långt', 'Omdömet var för långt att ta emot.', 413);
  }

  let omdome;
  try {
    const data = await lasFormular(request, MAX_KROPP);
    const falt = {};
    for (const [k, v] of data.entries()) if (typeof v === 'string') falt[k] = v;
    omdome = rensa(falt);
  } catch (e) {
    if (e instanceof ForStorKropp) return fel('För långt', 'Omdömet var för långt att ta emot.', 413);
    return fel('Något gick fel', 'Formuläret kunde inte läsas.', 400);
  }
  if (omdome.fel) return fel('Fyll i lite mer', omdome.fel, 400);

  try {
    const inbjudan = await env.KLICK.prepare('SELECT mal, anvand FROM inbjudan WHERE kod = ?')
      .bind(omdome.kod).first();
    if (!inbjudan) {
      return fel('Länken känns inte igen', 'Koden finns inte. Kontrollera att hela länken från mejlet kom med.', 400);
    }
    const anvand = () => fel('Länken är redan använd',
      'Ett omdöme har redan skickats med den här länken. Vill du ändra något, mejla mig.', 410);
    if (inbjudan.anvand) return anvand();

    // Båda i en transaktion, och båda bara om koden fortfarande är oanvänd.
    // Två samtidiga försök kan då aldrig ge två omdömen.
    const [insatt] = await env.KLICK.batch([
      env.KLICK.prepare(
        "INSERT INTO omdome (kod, mal, betyg, namn, ort, text, dag) " +
        "SELECT kod, mal, ?, ?, ?, ?, date('now') FROM inbjudan WHERE kod = ? AND anvand IS NULL"
      ).bind(omdome.betyg, omdome.namn, omdome.ort, omdome.text, omdome.kod),
      env.KLICK.prepare("UPDATE inbjudan SET anvand = date('now') WHERE kod = ? AND anvand IS NULL")
        .bind(omdome.kod)
    ]);
    if (!insatt.meta.changes) return anvand();

    // Notisen är en bekvämlighet. Omdömet är redan sparat, så ett fel här
    // ska kunden inte märka.
    if (env.RESEND_API_KEY) {
      const skick = skickaMejl(env.RESEND_API_KEY, notis(omdome, inbjudan.mal, avsandare, mottagare))
        .catch((e) => console.error('Notis om omdöme misslyckades: ' + e.message));
      if (waitUntil) waitUntil(skick); else await skick;
    }
  } catch (e) {
    console.error('Omdömet kunde inte sparas: ' + e.message);
    return fel('Kunde inte spara', 'Omdömet gick inte att spara just nu. Försök igen om en stund, eller mejla det.', 500);
  }

  return Response.redirect(new URL('/omdome/tack/', request.url).toString(), 303);
}

// En GET på endpointen är inget omdöme, skicka besökaren till skrivsidan
```

```js
'use strict';

/*
 * Omdömena på sajten: vilka som hör till en sida, snittet, och samma
 * uppgifter som strukturerad data till Google. Sidan och den strukturerade
 * datan räknas med samma funktioner, så de kan aldrig visa olika betyg.
 *
 * Publicerade omdömen står i src/_data/omdomen.json och skrivs av
 * verkstadspanelen. Ren logik, inga filer och inget nätverk.
 */

const MANADER = ['januari', 'februari', 'mars', 'april', 'maj', 'juni', 'juli',
  'augusti', 'september', 'oktober', 'november', 'december'];

function omdomenFor(lista, mal) {
  return (lista || [])
    .filter((o) => o.mal === mal)
    .sort((a, b) => (a.datum === b.datum ? b.id - a.id : a.datum < b.datum ? 1 : -1));
}

function betygssnitt(lista) {
  if (!lista.length) return { antal: 0, snitt: null };
  const summa = lista.reduce((s, o) => s + o.betyg, 0);
  return { antal: lista.length, snitt: Math.round((summa / lista.length) * 10) / 10 };
}

function betygText(tal) {
  return String(tal).replace('.', ',');
}

function manad(datum) {
  const m = /^(\d{4})-(\d{2})-\d{2}$/.exec(String(datum || ''));
  if (!m || !MANADER[Number(m[2]) - 1]) return '';
  return MANADER[Number(m[2]) - 1] + ' ' + m[1];
}

const betyg = (varde) => ({ '@type': 'Rating', ratingValue: varde, bestRating: 5, worstRating: 1 });

function strukturerat(lista) {
  if (!lista.length) return null;
  const { antal, snitt } = betygssnitt(lista);
  return {
    aggregateRating: { '@type': 'AggregateRating', ratingValue: snitt, reviewCount: antal, bestRating: 5, worstRating: 1 },
    review: lista.map((o) => ({
      '@type': 'Review',
      reviewRating: betyg(o.betyg),
      author: { '@type': 'Person', name: o.namn },
      datePublished: o.datum,
      reviewBody: o.text
    }))
  };
}

// Kundens text hamnar i ett <script>-block. Utan det här kunde en text med
// </script> avsluta blocket och resten tolkas som sidans egen kod.
function jsonld(varde) {
  return JSON.stringify(varde)
    .replace(/</g, '\\u003c').replace(/>/g, '\\u003e').replace(/&/g, '\\u0026');
}

module.exports = { omdomenFor, betygssnitt, betygText, manad, strukturerat, jsonld };
```

```js
'use strict';

/*
 * Ren logik för omdömena i verkstadspanelen: koder till inbjudningar,
 * vilka mål ett omdöme kan ha, och filen src/_data/omdomen.json där de
 * publicerade omdömena bor. Inget nätverk, så allt går att testa rakt av.
 */

const fs = require('node:fs');
const crypto = require('node:crypto');

const KOD = /^[A-Za-z0-9_-]{12}$/;

// Nio slumpade byte blir exakt tolv tecken i base64url, utan utfyllnad
function nyKod() {
  return crypto.randomBytes(9).toString('base64url');
}

function malLista(produkter) {
  return [{ mal: 'bestallning', namn: 'Efter mått (beställningssidan)' }].concat(
    produkter.slice().sort((a, b) => a.nr - b.nr)
      .map((p) => ({ mal: p.slug, namn: 'N:o ' + p.nr + '. ' + p.titel }))
  );
}

function giltigtMal(mal, produkter) {
  return mal === 'bestallning' || produkter.some((p) => p.slug === mal);
}

function las(fil) {
  let text;
  try {
    text = fs.readFileSync(fil, 'utf8');
  } catch (e) {
    if (e.code === 'ENOENT') return [];
    throw e;
  }
  const lista = JSON.parse(text);
  if (!Array.isArray(lista)) throw new Error(fil + ' ska innehålla en lista.');
  return lista;
}

// Samma omdöme två gånger blir ett. Det gör att Publicera kan tryckas igen
// om borttagningen ur D1 misslyckades förra gången.
function medOmdome(lista, rad) {
  if (lista.some((o) => o.id === rad.id)) return lista;
  return lista.concat([{
    id: rad.id, mal: rad.mal, betyg: rad.betyg, namn: rad.namn, ort: rad.ort, text: rad.text, datum: rad.dag
  }]);
}

function utanOmdome(lista, id) {
  return lista.filter((o) => o.id !== id);
}

// Frågorna går genom wrangler som text, utan bundna värden. Allt som
// skrivs in i dem går därför genom den här.
function sql(varde) {
  if (typeof varde === 'number') {
    if (!Number.isInteger(varde)) throw new Error('Bara heltal i SQL: ' + varde);
    return String(varde);
  }
  return "'" + String(varde).replace(/'/g, "''") + "'";
}

function lank(url, kod) {
  return url + '/omdome/#' + kod;
}

module.exports = { KOD, nyKod, malLista, giltigtMal, las, medOmdome, utanOmdome, sql, lank };
```

```js
'use strict';

const test = require('node:test');
const assert = require('node:assert/strict');
const path = require('node:path');
const Konfigurator = require('../assets/konfigurator.js');
const O = require('../lib/omdomen.js');

/*
 * Bygger sajten i minnet och läser varje block med strukturerad data. Ett
 * kommatecken för mycket i en mall gör blocket oläsligt för Google utan att
 * något syns på sidan, så det är här det fångas.
 */

const ROT = path.join(__dirname, '..');
const OMDOMEN = require('../src/_data/omdomen.json');

let sidor;
async function bygg() {
  if (sidor) return sidor;
  const mod = await import('@11ty/eleventy');
  const Eleventy = mod.Eleventy || mod.default;
  const elev = new Eleventy(path.join(ROT, 'src'), path.join(ROT, '_site'), {
    configPath: path.join(ROT, '.eleventy.js'), quietMode: true
  });
  sidor = await elev.toJSON();
  return sidor;
}

function block(html) {
  return [...html.matchAll(/<script type="application\/ld\+json">([\s\S]*?)<\/script>/g)].map((m) => JSON.parse(m[1]));
}

test('varje block med strukturerad data går att läsa', async () => {
  for (const s of await bygg()) {
    assert.doesNotThrow(() => block(s.content), s.url);
  }
});

test('beställningssidan är en Product vars lägsta pris står på sidan', async () => {
  const sida = (await bygg()).find((s) => s.url === '/bestallning/');
  const produkt = block(sida.content).find((b) => b['@type'] === 'Product');
  assert.ok(produkt, 'Product saknas på beställningssidan');
  assert.equal(produkt.offers['@type'], 'AggregateOffer');
  assert.ok(sida.content.includes(Konfigurator.formatera(Number(produkt.offers.lowPrice))), 'lägsta priset syns inte');
});

test('betyg finns i datan precis där omdömen syns på sidan', async () => {
  for (const s of await bygg()) {
    const produkter = block(s.content).filter((b) => b['@type'] === 'Product');
    for (const p of produkter) {
      const synligt = s.content.includes('class="omdomen__snitt"');
      assert.equal(Boolean(p.aggregateRating), synligt, s.url);
      if (p.aggregateRating) {
        const snitt = O.betygText(p.aggregateRating.ratingValue) + ' av 5';
        assert.ok(s.content.includes(snitt), s.url + ' visar inte ' + snitt);
        assert.equal(p.review.length, p.aggregateRating.reviewCount);
      }
    }
  }
});

test('startsidans företag har inget betyg', async () => {
  const start = (await bygg()).find((s) => s.url === '/');
  for (const b of block(start.content)) assert.equal(b.aggregateRating, undefined);
});

test('omdomen.json har bara giltiga omdömen', () => {
  assert.ok(Array.isArray(OMDOMEN));
  for (const o of OMDOMEN) {
    assert.ok(Number.isInteger(o.id) && o.betyg >= 1 && o.betyg <= 5 && o.namn && o.text && O.manad(o.datum), JSON.stringify(o));
  }
  assert.equal(new Set(OMDOMEN.map((o) => o.id)).size, OMDOMEN.length, 'två omdömen delar id');
```
